# Coongram 🐾

Интерактивная социальная платформа для животных: посты, лайки, поиск, профили пользователей.

---

## 📝 Функционал
- Лента постов и лайки  
- Поиск пользователей и животных  
- Профили с информацией о питомцах  
- Адаптивная верстка (desktop → mobile)
